# Регрессионные разметки

Прогонять после любого изменения `render.ps1` или справочника синтаксиса — последовательно, по одной. Экранный прогон занимает экран: окно 1С разворачивается, клики идут по координатам экрана, вставка — через общий буфер обмена, поэтому два прогона одновременно мешают друг другу, а пользователь в это время не должен работать за компьютером:

```powershell
$f = "skills\md-design-render-screen\scripts\render.ps1"
foreach ($t in Get-ChildItem tests\regression\*.txt) {
  & powershell -NoProfile -ExecutionPolicy Bypass -File $f -Markup $t.FullName `
    -OutDir "tests\runs\regression\$($t.BaseName)" -Prefix $t.BaseName
  "$($t.Name): exit $LASTEXITCODE"
}
```

Код 1 на разметке `ok-` или `visual-` — не обязательно дефект разметки: скрипт останавливается и тогда, когда окно 1С не удалось сделать активным (пользователь работал за компьютером). Текст ошибки в выводе скрипта различает эти случаи; при остановке из-за фокуса прогон повторить, не трогая компьютер. Предупреждение «Страница … не открылась после двух кликов» — повод открыть снимки и проверить, пуста ли страница.

Каталог `tests/runs/` в `.gitignore`. Префикс имени файла задаёт ожидаемый исход: `ok-` — форма формируется, `error-` — скрипт останавливается с ошибкой, `visual-` — форма формируется, а результат проверяется просмотром снимков.

| Файл | Ожидаемый исход | Что проверяет |
| ---- | --------------- | ------------- |
