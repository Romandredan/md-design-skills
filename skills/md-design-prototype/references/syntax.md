## 1. Заголовок формы

```text
--- Заголовок формы ---
```

Первая строка описания. Без неё форма получает заголовок «<Без заголовка>».

## 2. Поля ввода

```text
Заголовок: Значение__ВСХОД {Свойство = Значение}
```

Тип определяется по значению: `01.01.2025` — дата, `17:15` — время, `01.01.2025 10:00:00` — дата и время, `5.00` / `11,11` — число, остальное — строка. Явный тип: `{Тип = Строка(100)}`, составной — `{Тип = Строка(10), Число(15), Булево}`. Правила: `Число(Длина, Точность)`, `Дата(ДатаВремя|Дата|Время)`, `Строка(Длина)`.

Кнопки поля — модификаторы после `__`: `В` выбор, `С` список, `Х` очистка, `О` открытие, `Д` регулирование. Пример ссылочного поля: `Контрагент: ООО Ромашка__ВО`.

Многострочное поле — строки из подчёркиваний под значением, их число задаёт высоту:

```text
Описание: Текст
          _____
          _____
```

## 3. Флажки и выключатели

```text
[X] Флажок включён
[ ] Флажок выключен
Флажок справа []
[0| ] Выключатель выключен
[ |1] Выключатель включён
```

## 4. Переключатели

```text
Способ: (X)Вариант 1 ( )Вариант 2
(X)Без заголовка ( )Второй
Вид: (X)Тумблер ( )Второй {ВидПереключателя = Тумблер}
```

## 5. Надписи

Любая строка, которую разбор не отнёс к другому элементу: `Текст надписи {ЦветТекста = Красный}`. Цвета — веб-цвета 1С из макета `Цвета` обработки (`Зеленый`, `Красный`, `Синий`, `Серый`, `Золотой`, `Коралловый` …).

## 6. Кнопки и командная панель

```text
< Записать и закрыть {ЦветФона = Золотой} | Записать | @Печать Печать >
```

Одна кнопка в `< >` рисуется без командной панели. `@ИмяКартинки` — картинка из библиотеки. `КнопкаПоУмолчанию = Истина` кнопку в «Накидке» визуально не выделяет; акцентную жёлтую кнопку дают `{ЦветФона = Золотой}`. Меню и подменю (с v0.12.1 пункты после `-` помечаются точками):

```text
< Записать | - | Печать
Печать
. Акт
. Счет
.. Счет на оплату >
```

## 7. Группы

Колонки групп: заголовки через `#` в одной строке, содержимое второй и следующих колонок — после `+`, с отступом (с v0.12.1 отступ обязателен и для одиночной вертикальной группы):

```text
#Клиент                 #Визит
  Клиент: Иванов__ВО    +Адрес: Москва
  Почта: a@b.ru         +Время: 15:00
```

Пустой заголовок `#` — группа без заголовка. Вложенные группы допустимы (`+#Подгруппа 1 #Подгруппа 2`). Вид группы — числом решёток: `#` без отображения, `##` слабое, `###` обычное, `####` сильное, `#####` свёртываемая, `######` всплывающая.

Однострочная группа: `Номер: 000001 & от: 01.01.2025`.

## 8. Страницы

```text
/Страница 1
  Элемент 1
/Страница 2
  Элемент 2
```

Содержимое страницы — с отступом. Вложенные страницы допустимы (отступ + `/`). Строка без отступа после страниц (например, общая командная панель) выводится под страницами.

## 9. Таблицы и деревья

```text
| Колонка 1 | Колонка 2 |
| --------- | --------: |
| Текст     |    100.00 |
```

- `:` в строке-разделителе — выравнивание (`:---` лево, `:---:` центр, `---:` право).
- Тип колонки — по значениям; один нечисловой текст делает колонку строковой. Явный тип: `| Значение {Тип = Число(15)} |`.
- Флажки: ячейки вида `[X] Текст` / `[ ] Текст` — колонка с флажком и текстом.
- Дерево: точки в начале ячейки задают уровень (`. Подстрока`, `.. Подподстрока`). На форме дерево показывается свёрнутым до корневых строк, поэтому на снимке видны только они; если важны подчинённые строки, покажи их обычной таблицей.
- Многострочный заголовок: `| -Группа- ||` над строкой подзаголовков; многоуровневые строки — `||` в конце строки объединяет ячейки.

## 10. Горизонтальное положение

```text
Лево
->                          Право
->          По центру          <-
Растягивать:                    ->
```

Для поля, флажка, переключателя и надписи работает. Перед командной панелью `->` кнопку вправо не сдвигает (проверено v0.16.4).

## 11. Свойства элементов

`{Имя = Значение}` после элемента передаётся в свойство элемента формы. Несколько свойств разделяются точкой с запятой: `{ЦветФона = Красный; ЦветТекста = Белый}` (так их соединяет форматтер самой «Накидки»); запятая разделяет значения внутри одного свойства, например типы в `{Тип = Строка(10), Число(15)}`.

Проверенные прогоном: `ЦветТекста`, `ЦветФона`, `Тип`, `ВидПереключателя`, `Доступность` (`{Доступность = Ложь}` делает кнопку и флажок бледными, недоступными — проверено 29.10.2026 на кнопке и флажке). Поле без значения получает тип из явного свойства: `Дата отгрузки: {Тип = Дата(Дата)}` — пустое поле даты; без `{Тип = …}` пустое поле становится строковым. `КнопкаПоУмолчанию = Истина` разбор принимает, но кнопку визуально не выделяет ни отдельно, ни вместе с другими свойствами; акцентную кнопку делает `ЦветФона = Золотой`. Остальные имена свойств элементов формы 1С, вероятно, работают, но перед использованием их нужно проверить прогоном.

## 12. Ловушки разбора (проверено прогонами)

| Что написано | Что получилось | Как писать |
| ------------ | -------------- | ---------- |
| `/` в любом месте строки, например размер `Б/Р` в ячейке | Значение обрезано на косой черте («Б»); остаток строки разбирается как страница — в многоколоночной строке таблицы появилась лишняя закладка «Р» с обрывком строки | Без косой черты: «Единый», «б.р.» |
| `+` в начале значения в группе из колонок, например `Телефон: +7 900…` | `+` прочитан как разделитель колонок: поле остаётся пустым, а остаток «7 900 …» выводится надписью вне группы (под страницами формы) | `8 900 …` или `7 (900) …` |
| Двоеточие в тексте надписи: `Внимание: товар не найден` | Поле ввода «Внимание» со значением | Запятая или точка вместо двоеточия |
| ` — ` (тире с пробелами) в надписи | Две отдельные надписи; свойство вроде `ЦветТекста` действует только на вторую | Запятая, точка или «что» |
| Кавычки-ёлочки `«»` в ячейке таблицы | Строка таблицы разбивается | Без кавычек |
| Путь с обратной косой чертой и подчёркиванием в значении поля: `Файл: C:\Прайсы\Север_ноябрь.xlsx__В` | В поле «C:ПрайсыСевер»: обратные косые черты пропадают, остаток после подчёркивания отбрасывается (так и в тонком, и в веб-клиенте) | Путь без них: `Файл: Север-ноябрь.xlsx__В` или прямые косые черты внутри не использовать — они создают страницу |
| Две таблицы подряд без элемента между ними | Форма не формируется: окно «К сожалению, возникла непредвиденная ошибка» (в журнале — «Значение не является значением объектного типа (Свойство)»); `render.ps1` останавливается с сообщением и снимком окна | Надпись между таблицами (заголовок второй таблицы) |
| Несколько свойств через запятую: `{КнопкаПоУмолчанию = Истина, ЦветФона = Золотой}` | Не применяется ни одно свойство, ошибки нет | Через точку с запятой: `{КнопкаПоУмолчанию = Истина; ЦветФона = Золотой}` |
| `{КнопкаПоУмолчанию = Истина}` как способ выделить главную кнопку | Кнопка выглядит обычной | `{ЦветФона = Золотой}` |
| Код из одних цифр: `ИНН: 0000000000` | Числовое поле с разделителями разрядов «0 000 000 000» | `ИНН: 0000000000 {Тип = Строка(12)}` — так же для КПП, БИК, штрихкодов, номеров |
