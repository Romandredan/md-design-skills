# Прогон «Накидки» в тонком клиенте (с экраном)

Исполнитель запускает тонкий клиент 1С с обработкой «Накидка» во временной базе, вставляет разметку, нажимает «Сформировать» и снимает каждую страницу формы. Работает через окно на экране: клики и клавиши эмулируются, снимки берутся с экрана.

## Вызов

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "<каталог навыка>\scripts\render.ps1" `
  -Markup "<файл разметки .txt, UTF-8>" -OutDir "<каталог снимков>" -Prefix "<имя>" [-KeepOpen]
```

Результат — JSON `{ pages, files, notOpened, pid }`, код 0. Ошибка — исключение с текстом, код 1; если причина — окно ошибки 1С, рядом `<Prefix>-error.png`. Сразу после запуска скрипт печатает `MDDESIGN_PID=<N>`: с `-KeepOpen` останавливать только этот процесс.

## Что делает скрипт

1. Находит тонкий клиент последней установленной версии (`-PlatformBin` — явно).
2. Готовит песочницу `%LOCALAPPDATA%\md-design-sandbox`: `MDDesign.epf` из последнего выпуска, пустую файловую базу `ib`.
3. Дописывает `DisableUnsafeActionProtection=.*md-design-sandbox.*` в пользовательский `%LOCALAPPDATA%\1C\1cv8\conf\conf.cfg` (прежние строки сохраняются). Без этого поле HTML обработки показывает «Предупреждение безопасности» и запуск висит до ответа человека. Действует только на базы с `md-design-sandbox` в пути.
4. Запускает `1cv8c.exe ENTERPRISE /Execute <epf>`, разворачивает окно и вводит разметку через буфер обмена (Ctrl+A, Ctrl+V через `keybd_event`), нажимает «Сформировать».
5. Находит закладки страниц по пикселям, снимает и обрезает каждую страницу.
6. Останавливает свой клиент по PID, возвращает прежнее содержимое буфера обмена.

## Защиты

- **Ввод только в окно 1С.** Перед каждым кликом, сочетанием клавиш и снимком скрипт проверяет, что активно окно 1С, и пытается его активировать. Не вышло — остановка с ошибкой, ввод не отправляется: иначе клики и вставка ушли бы в окно, в котором работает пользователь.
- **Окно ошибки 1С** (модальное окно процесса, класс `V8TopLevelFrameSDIsec`) после открытия обработки и после формирования — снимок окна и остановка.
- **Форма не сформировалась** (редактор загрузился позже вставки) — до трёх повторов.
- **Закладка не открылась** — повторный клик; иначе предупреждение и поле `notOpened`.

## Ограничения

- Экран пользователя занят около минуты на прогон; пользователь в это время не должен работать за компьютером. Предупреждать перед запуском; серии больше пяти прогонов согласовывать.
- Прогоны строго последовательно: общие экран и буфер обмена.
- Координаты рассчитаны на развёрнутое окно и интерфейс «Накидки» v0.16; от разрешения и масштаба экрана зависят поиск закладок и обрезка — при сбое смотреть `<Prefix>-debug.png`.
- Снимаются страницы верхнего уровня и видимая часть окна.
