# Прототип → внешняя обработка

Результат — внешняя обработка `.epf`, её XML-выгрузка (для правки и хранения в репозитории) и снимки собранной формы. Форма строится по тому же дереву разбора, по которому «Накидка» рисует прототип, поэтому структура совпадает с согласованными экранами: страницы, группы колонок, однострочные группы, поля и их кнопки, флажки и выключатели, переключатели, надписи, таблицы и деревья, командные панели.

## Вызов

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "<каталог навыка>\scripts\markup-to-epf.ps1" `
  -Markup "<разметка прототипа .txt>" -OutDir "<каталог результата>" -Name "<ИмяОбработки>" [-NoSnapshot]
```

`-Name` — имя объекта 1С: буквы, цифры, подчёркивание, не с цифры. Результат — JSON: `epf`, `xml` (каталог выгрузки), `generator` (`elements`, `attributes`, `commands`, `notTransferred`), `snapshots`, `error`. Прогон занимает около 15 секунд после подготовки окружения веб-исполнителя.

## Как устроено

1. Окружение — `md-design-render-web\scripts\render.ps1 -PrepareOnly` (Apache, Firefox, исходники «Накидки», служебная база для сборки).
2. Дерево разбора: страница редактора «Накидки» (`index.html` из макета `БиблиотекаJS`) открывается в Firefox без окна, разметка передаётся функцией `window.setText`, дерево берётся из события `EVENT_CHANGE_CONTENT` — того же, по которому 1С строит прототип (`scripts/tree.mjs`). Своего разбора разметки нет.
3. XML-выгрузка (`scripts/gen-epf.mjs`) — по правилам модуля «ПостроительСхемФормы» «Накидки»: виды групп и их `Группировка`, флажок и значение в одной ячейке таблицы, единственная кнопка вне командной панели. Порядок тегов в `Form.xml` снят с 1500 форм типовой конфигурации. Цвета — из макета «Цвета» «Накидки».
4. Сборка — `1cv8 DESIGNER /LoadExternalDataProcessorOrReportFromFiles`.
5. Снимок — `render.ps1 -OpenEpf`: веб-исполнитель открывает собранную обработку и снимает каждую страницу.

## Что получает разработчик и чего нет

- Реквизиты формы с типами из разметки (`Строка`, `Число` с длиной и точностью, `Дата` с составом даты, `Булево`); тип колонок таблиц без явного `{Тип = …}` выводится по значениям примера.
- Таблицы — реквизиты-таблицы значений (деревья — деревья значений) с колонками.
- Кнопки — команды формы с обработчиками-заготовками `Команда<ИмяКнопки>` в модуле формы (префикс нужен: кнопки «Закрыть», «Записать» совпали бы с методами формы).
- **Не переносится** (перечислено в `notTransferred`): данные примера (строки таблиц, значения полей), картинки кнопок, ссылочные типы (во внешней обработке без конфигурации они заменяются строкой), свойства, которых генератор не знает. Это перечисли разработчику вместе с результатом.

## Проверка

Посмотри снимки собранной формы рядом со снимками прототипа: расположение должно совпадать, поля — пустые. Окно ошибки при открытии (поле `error`) — ошибка генератора: текст ошибки в отчёте `*-error-report.zip` (`report.json`, ключ `applicationErrorInfo`), с ним — к автору навыка.
